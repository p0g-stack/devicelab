KernelSU userspace cli

Usage: ksud <COMMAND>

Commands:
  module          Manage KernelSU modules
  post-fs-data    Trigger `post-fs-data` event
  services        Trigger `service` event
  boot-completed  Trigger `boot-complete` event
  late-load       Load kernelsu.ko and execute late-load stage scripts
  soft-reboot     Emulate system reboot
  insmod          Load a kernel module with kallsyms access
  install         Install KernelSU userspace component to system
  unload          Unload KernelSU kernel module (LKM Only)
  uninstall       Uninstall KernelSU modules and itself(LKM Only)
  sepolicy        SELinux policy Patch tool
  profile         Manage App Profiles
  feature         Manage kernel features
  boot-patch      Patch boot or init_boot images to apply KernelSU
  boot-restore    Restore boot or init_boot images patched by KernelSU
  boot-patch-v2   Patch KernelSU into a boot image
  boot-info       Show boot information
  debug           For developers
  kernel          Kernel interface
  resetprop       Resetprop - Magisk-compatible system property tool
  initrc          Manage initrc injection
  help            Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
Load kernelsu.ko and execute late-load stage scripts

Usage: ksud late-load [OPTIONS]

Options:
      --magica [<MAGICA>]            Use adb root to execute late-load for jailbreaking by Magica
      --allow-shell                  Pass allow_shell=1 when loading kernelsu.ko
      --post-magica                  Restore adb properties after magica late-load
      --kmi <KMI>                    Specify kernel KMI version instead of auto-detection
      --package-name <PACKAGE_NAME>  manager package name [default: me.weishu.kernelsu]
  -h, --help                         Print help
Load a kernel module with kallsyms access

Usage: ksud insmod <MODULE> [PARAMS]...

Arguments:
  <MODULE>     kernel module path
  [PARAMS]...  module load parameters (e.g. key=val key2=val2)

Options:
  -h, --help  Print help
Show boot information

Usage: ksud boot-info <COMMAND>

Commands:
  current-kmi           show current kmi version
  supported-kmis        show supported kmi versions
  is-ab-device          check if device is A/B capable
  default-partition     show auto-selected boot partition name
  available-partitions  list available partitions for current or OTA toggled slot
  slot-suffix           show slot suffix for current or OTA toggled slot
  help                  Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
Manage App Profiles

Usage: ksud profile <COMMAND>

Commands:
  get-sepolicy     get root profile's selinux policy of <package-name>
  set-sepolicy     set root profile's selinux policy of <package-name> to <profile>
  get-template     get template of <id>
  set-template     set template of <id> to <template string>
  delete-template  delete template of <id>
  list-templates   list all templates
  help             Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
For developers

Usage: ksud debug <COMMAND>

Commands:
  set-manager     Set the manager app, kernel CONFIG_KSU_DEBUG should be enabled
  get-sign        Get apk size and hash
  su              Root Shell
  version         Get kernel version
  test            For testing
  extract-binary  Extract an embedded binary to a specified path
  mark            Process mark management
  sulogd          Launch sulogd daemon manually
  info            Get kernel info
  package         Print default package name
  help            Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
Manage kernel features

Usage: ksud feature <COMMAND>

Commands:
  get    Get feature value and support status
  set    Set feature value
  list   List all available features
  check  Check feature status (supported/unsupported/managed)
  load   Load configuration from file and apply to kernel
  save   Save current kernel feature states to file
  help   Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
Manage KernelSU modules

Usage: ksud module <COMMAND>

Commands:
  install         Install module <ZIP>
  undo-uninstall  Undo module uninstall mark <id>
  uninstall       Uninstall module <id>
  enable          enable module <id>
  disable         disable module <id>
  action          run action for module <id>
  list            list all modules
  config          manage module configuration
  help            Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
