Manage App Profiles

Usage: ksud profile <COMMAND>

Commands:
  get-sepolicy     get root profile's selinux policy of <package-name>
  set-sepolicy     set root profile's selinux policy of <package-name> to <profile>
  get-template     get template of <id>
  set-template     set template of <id> to <template string>
  delete-template  delete template of <id>
  list-templates   list all templates
  help             Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
